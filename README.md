# SoundTrackFirst

Static GitHub Pages rebuild of [soundtrackfirst.com](https://soundtrackfirst.com/).

The deployable site is contained in [`site/`](site/). A GitHub Actions workflow
publishes that directory to GitHub Pages whenever `site/` changes on `main`.

Public routes mirrored from the source sitemap:

- `/`
- `/home-full`
- `/formats`
- `/login`
- `/signup`
- `/create-soundtrack`
- `/community-sessions`
- `/festival-classroom-toolkit`
- `/feature-cut-storyboard`
- `/metamorphosis-from-within`
- `/precious-commodities`
- `/baja`
- `/joe-bonamassa`
- `/scores`
- `/try-it`
